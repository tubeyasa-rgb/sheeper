# أرخص مشوار

تطبيق Android لتسجيل العروض ومقارنتها محليًا. لا يوجد خادم أو تسجيل حساب. لا يُنشئ التطبيق عروض أسعار، ولا يضمن السعر أو التوفير عند الحجز.

## البناء

افتح المشروع في Android Studio أو شغّل `./gradlew assembleDebug testDebugUnitTest` باستخدام JDK 17 أو 21 وAndroid SDK 36. نسخة التصحيح: `app/build/outputs/apk/debug/app-debug.apk`. الحد الأدنى Android 8 (API 26). البناء الأول يحتاج تنزيل الاعتمادات من Google وMaven Central وGradle.

## الوظائف

- واجهة Kotlin وCompose وبيانات محلية Room. عند التحديث من النسخة السابقة يحاول التطبيق استيراد سجل SQLite القديم دون حذفه.
- إدخال عرض يدويًا أو مشاركة صورة/اختيارها لقراءة النص على الجهاز عبر مكتبة ML Kit المضمّنة. يجب مراجعة العرض وإدخاله وتأكيده؛ الصور لا تُحفظ. نموذج OCR المستخدم لا يدعم كل النصوص العربية، لذا قد يلزم الإدخال اليدوي.
- مقارنة العروض المدخلة حديثًا خلال ثلاث دقائق للمسار والفئة نفسيهما؛ منع التكرار خلال 90 ثانية؛ حذف عرض أو كل السجل.
- نطاق تاريخي تقديري لمزوّد ومسار وفئة العينة الأخيرة فقط، بعد توفر 40 عينة واجتياز اختبار زمني للتغطية والخطأ مقارنة بالوسيط. بخلاف ذلك يمتنع عن التوقع. النطاق ليس سعرًا مباشرًا ولا ضمانًا.
- تسجيل السعر المقبول والمدفوع ونجاح الحجز كبيانات منفصلة عن السعر المعروض.
- أوقات المغادرة الآن وبعد ٥ و١٠ و١٥ و٣٠ دقيقة؛ يعتمد التوقع على ساعة القاهرة وتحقق تاريخي، وليس على بيانات لحظية.
- تسجيل نقاط يحددها المستخدم باعتبار سلامتها غير معروفة أو غير آمنة؛ لا يوجد مصدر تحقق يسمح بتصنيفها آمنة أو التوصية بها.
- تصدير واستيراد سجل مشفّر محليًا بكلمة مرور باستخدام AES-GCM وPBKDF2؛ فقدان كلمة المرور يمنع الاستعادة. الاستيراد يضيف السجل دون حذف البيانات الموجودة.
- فتح بحث أو خرائط خارجية بإرادة المستخدم. نتائج البحث ليست أسعارًا مؤكدة.

## حدود مهمة

التطبيق لا ينفذ الحجز أو الالتقاط التلقائي للشاشة أو الحصول على عروض من تطبيقات أخرى. لا توجد بعد خرائط مشاة غير متصلة أو تحقق من سلامة نقطة الالتقاط، لذا لا يوصي بتغييرها. لم تُنفّذ كل تفاصيل مواصفات المشروع، ومنها التقييم التجريبي الكامل، والتحقق من سلامة نقاط الالتقاء باستخدام مصدر موثوق، والتحكم في الاحتفاظ والإتاحة الكاملة. بيانات النسخ المشفّرة محلية ويختار المستخدم مكان حفظ الملف. إزالة التطبيق تحذف بياناته المحلية؛ صدّر نسخة احتياطية قبل ذلك.

## الاختبارات

`./gradlew testDebugUnitTest` لاختبارات المنطق والنسخ المشفر. `./gradlew connectedDebugAndroidTest` لتشغيل اختبارات الواجهة وقاعدة البيانات على جهاز أو محاكي متصل.
